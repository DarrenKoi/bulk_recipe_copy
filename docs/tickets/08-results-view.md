# 08: 결과 화면

**What to build:** 결과를 장비 → 레시피 → 파일 순으로 펼칩니다. 진행 중에는 "진행 중"과 실패·
불명확 건수, 모든 파일이 끝나면 장비별 최종 결과(불명확 > 일부 실패 > 전부 검증됨)를 봅니다.
처리율 100%와 전체 성공을 구분하고, 끝나면 요약이 뜹니다.

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] `GET /api/jobs/{id}`가 트리와 집계를 돌려줌. FTP 계정·로컬 스냅샷 경로는 넣지 않음
- [ ] 수집 전(행 없음)은 성공도 100%도 아님. file이 남아 있으면 최종 결과를 정하지 않음

- [ ] 레시피를 다 보낸 뒤 대상 raw 폴더를 LIST해 "대상에만 있는 파일 n개" 기록·표시

- [ ] pytest: 집계 규칙(진행 중/최종, 우선순위, 처리율과 성공), 대상에만 있는 파일 수
