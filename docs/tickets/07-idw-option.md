# 07: `.idw` 옵션

**What to build:** 실행자가 `.idw` 포함을 켤 수 있고(기본 끔), 켜면 "같은 idw를 쓰는 다른
레시피도 영향받음" 문구를 봅니다. 공유 `.idw`는 대상마다 한 번만 보냅니다.

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] job에 idw 포함 여부를 기록하고 스냅샷·manifest에 `data/{idw}.idw`가 들어감
- [ ] 사전 점검과 첫 쓰기 전 재확인이 `.idw` 존재도 봄
- [ ] 같은 대상에 같은 `.idw`는 한 번만 전송. job에 남은 레시피 중 그 `.idw`를 쓰는 것 하나라도 덮어쓰기를 허락받았으면 덮어쓰기 모드. 결과는 관련 레시피 모두에 보임
- [ ] 화면: 켜고 끄기, 켰을 때 문구
- [ ] pytest: 기본 끔이면 `.idw` 무전송, 켜면 대상당 한 번, 허락 계산
