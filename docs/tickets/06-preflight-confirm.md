# 06: 사전 점검과 확인 팝업

**What to build:** 실행 전 확인 팝업이 대상마다 상태를 알리고 실행자가 고릅니다. class 폴더가
없으면 "만들까요?"(거절하면 그 대상만 빠짐), 다른 fab에 같은 class가 있으면 경고, 같은
레시피가 있으면 덮어쓸지 고릅니다. 허락받은 (대상, 레시피) 쌍만 덮어쓰기 모드로 보냅니다.

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] `POST /api/preflight`가 `class_missing`, `class_exists_other_fab`, `recipe_exists`를 읽기만으로 돌려줌
- [ ] job 생성은 선택(대상, 레시피, 허락 쌍, 폴더 허락 대상)을 그대로 기록하고 사전 점검을 다시 돌리지 않음. 허락 쌍·폴더 허락은 job 자신의 선택 안이어야 함
- [ ] 폴더 허락 대상은 class 폴더(`{class}/`, `{class}/data/`)를 만들고 진행. 거절한 대상과 허락 안 한 쌍은 job에서 빠짐. 남는 게 없으면 생성 거부
- [ ] 허락받은 쌍은 덮어쓰기 모드, 나머지는 05의 첫 쓰기 전 재확인
- [ ] 확인 팝업에 장비 수·레시피 수·파일 수·총 크기
- [ ] pytest: 세 항목, 폴더 생성 후 복사, 거절 대상 제외, 허락 쌍만 교체, 허락 없는 쌍은 대상 무변경
