# 11: 원본 변경 탐지

**What to build:** 원본 레시피가 수집 중에 바뀌고 있으면 한 번 더 수집하고, 또 바뀌면 job이
막힙니다. 반쯤 편집된 레시피가 퍼지지 않습니다.

**Blocked by:** 04

**Status:** ready-for-agent

- [x] 수집 전후 목록(경로·크기·mtime) 비교. 다르면 재수집, 또 다르면 `차단("원본이 바뀌는 중")`
- [x] 스펙 문구대로 "탐지이지 증명이 아님"을 결과 화면이나 문서에 남김
- [x] pytest: 가짜 장비가 수집 중 원본을 한 번/두 번 바꾸는 두 경우

**Notes:** 비교 목록은 수집할 파일 목록과 같은 순회(`_recipe_files`)에서 나옵니다. `.idp`도 idw 폴더 LIST에서 크기·mtime을 얻어 비교에 넣습니다. 이 비교는 탐지이지 증명이 아닙니다. 두 목록 사이에 크기와 mtime이 같게 바뀐 파일은 잡지 못하고, Unix LIST의 mtime은 분 단위라 같은 분 안에 크기가 같게 바뀐 것도 놓칩니다. 이 한계는 `backend/jobs.py`의 `collect` 주석과 여기에 남겼습니다. 결과 화면에는 차단 사유 "원본이 바뀌는 중"이 그대로 보입니다.
